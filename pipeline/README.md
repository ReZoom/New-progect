# Пайплайн «Витрина», версия 1

Из строки в таблице товаров делает готовый вертикальный ролик 1080×1920: сценарий от нейросети, озвучка через локальную VoiceStudio, фото товара с плавным наездом, крупные субтитры по словам, обложка. Публикует в Telegram-витрину.

Что делает человек: добавляет товар в таблицу, смотрит готовый ролик, нажимает «опубликовать». Остальное делают скрипты.

## Установка на Windows

1. Python 3.11 или новее: https://www.python.org/downloads/ , при установке поставить галочку «Add to PATH».
2. FFmpeg: скачать сборку с https://www.gyan.dev/ffmpeg/builds/ (файл `ffmpeg-release-essentials.zip`), распаковать в `C:\ffmpeg`, добавить `C:\ffmpeg\bin` в PATH. Проверка в новом окне PowerShell: `ffmpeg -version`.
3. VoiceStudio уже стоит. Запустите приложение, оно поднимает сервер на `http://localhost:3900`.
4. В папке `pipeline`:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy config.example.yaml config.yaml
```

## Проверка установки за одну команду

```powershell
python -m vitrina demo
```

Соберёт тестовый ролик без нейросетей и без VoiceStudio: тишина вместо голоса, заглушка вместо фото. Файл появится в `data\out\demo-001\demo-001.mp4`. Если он открывается, в нём есть субтитры и картинка плавно наезжает, FFmpeg и Python настроены правильно.

## Настройка

Откройте `config.yaml`.

Озвучка. Посмотрите, какие голоса есть в VoiceStudio:

```powershell
python -m vitrina voices
```

Впишите id нужных голосов в `tts.voices_by_channel`, по одному на канал. Разные голоса на разных каналах нужны, чтобы площадки не связывали каналы между собой.

Сценарии. Получите ключ на https://openrouter.ai , положите его в переменную окружения `OPENROUTER_API_KEY` или прямо в `llm.api_key`. Модель по умолчанию `deepseek/deepseek-chat`, сценарий стоит доли копейки. Без ключа пайплайн делает шаблонный сценарий из описания, это годится только для проверки.

Субтитры. По умолчанию тайминги слов берутся из транскрипции той же VoiceStudio. Если в ней не установлена модель распознавания, поставьте `stt.provider: none`, слова распределятся по времени равномерно. Для коротких роликов это почти незаметно.

Музыка. Положите несколько треков с лицензией на коммерческое использование в `data\music`, пайплайн будет выбирать случайный и подмешивать тихо. Папки нет или она пуста: ролик без музыки.

Telegram. Создайте бота через @BotFather, добавьте его администратором в канал-витрину, впишите токен и `@username` канала.

## Работа

Таблица товаров: `data\products.csv`, пример в `data\products.example.csv`. Колонки:

| Колонка | Что писать |
|---|---|
| id | короткий уникальный код, например `dom-001` |
| channel | код канала: `dom`, `avto`, `masterskaya`, `gik` |
| title, description, price | из карточки товара, в описание можно вставить 2–3 лучших отзыва |
| affiliate_url | партнёрская ссылка из кабинета Ozon Blogger |
| images | пути к файлам или ссылки на фото через точку с запятой, 1–5 штук |
| commission_pct | ставка по категории, для аналитики |
| status | `new` для новых, остальное пайплайн ставит сам |

Команды:

```powershell
python -m vitrina script dom-001          # 3 варианта сценария, выбран первый
python -m vitrina script dom-001 --pick 2 # выбрать второй вариант
python -m vitrina build dom-001           # озвучка, субтитры, сборка, обложка
python -m vitrina run --channel dom       # всё новое по каналу
python -m vitrina run --limit 10          # первые 10 новых товаров
python -m vitrina publish dom-001         # отправить в Telegram-витрину
```

Результат по каждому товару лежит в `data\out\<id>\`: `script.json`, `script.txt`, `voice.wav`, `subs.ass`, `<id>.mp4`, `<id>_cover.png`. Варианты сценария в `script_variants.json`.

Ролик не понравился: удалите папку `data\out\<id>` и запустите `script` с другим `--pick` или просто заново, модель даст новые варианты.

## Чек-лист проверки ролика

- Первая секунда понятна без звука.
- Факты совпадают с карточкой товара.
- В конце есть призыв «Ссылка в закрепе».
- На фото нет чужих логотипов и водяных знаков.

## Структура

```
vitrina/
  cli.py        команды
  config.py     настройки
  ledger.py     таблица товаров и статусы
  llm.py        сценарий через OpenRouter или шаблон
  tts.py        озвучка через VoiceStudio, заглушка для тестов
  stt.py        тайминги слов
  visuals.py    кадры 9:16 и обложка
  subtitles.py  субтитры ASS
  assemble.py   FFmpeg: наезд, склейка, звук, субтитры
  publish.py    Telegram
prompts/script_ru.txt   промпт сценария, правьте под свой стиль
```
