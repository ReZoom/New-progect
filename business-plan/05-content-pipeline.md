# 05. Контент-завод: техническая схема

Цель: ролик 20–40 секунд в формате 9:16 за 15–20 минут человеческого времени. Всё, что можно, крутится локально на RTX 4060 8 ГБ.

## 1. Схема

```
Подбор товара → Сценарий → Визуал → Озвучка → Сборка → Проверка → Публикация → Учёт
   (человек)     (LLM)    (локально)  (TTS)   (FFmpeg)  (человек)  (API)      (скрипт)
```

Человек участвует в двух шагах: подбор товара и проверка готового ролика. Всё остальное делают скрипты.

## 2. Шаги и инструменты

### Подбор товара

- Источник: каталог в кабинете Ozon Blogger, фильтр по категории с высокой ставкой, рейтинг 4,8 и выше, от 500 отзывов, цена 500–3 000 ₽.
- Правило: один товар даёт один ролик на одном канале. Один и тот же товар на разных каналах раз в 2 недели допустим с другим сценарием.
- Хранение: таблица с полями товар, ссылка, категория, ставка, канал, статус.

### Сценарий

- Модель: DeepSeek или Qwen через OpenRouter, запрос стоит доли копейки.
- Шаблон: первые 2 секунды боль или интрига, затем 3 факта по 5 секунд, затем призыв «ссылка в закрепе». 60–80 слов.
- Запрос содержит описание товара из карточки и 3 лучших отзыва. Модель запрещено придумывать свойства, которых нет в карточке.
- Пять сценариев на один товар, человек выбирает один. Это 2 минуты.

### Визуал

Три источника, по приоритету:

1. Фото товара из партнёрского кабинета. Эффект Кена Бёрнса: плавный наезд и панорама, 3–5 секунд на кадр.
2. Сгенерированные локально фоны и сцены: ComfyUI, модель Flux Schnell в квантованном виде или SDXL Lightning. На 4060 кадр 1080×1920 за 10–20 секунд.
3. Стоковые вертикальные ролики с лицензией на коммерческое использование: Pexels, Pixabay.

Облачная видеогенерация Kling или Hailuo только для первого кадра, где нужно движение. Один клип 5 секунд, 10–20 клипов в месяц на базовом тарифе.

Локальная видеогенерация на 8 ГБ: модели LTX-Video и Wan 2.1 в версии 1,3 млрд параметров запускаются, но клип 5 секунд занимает 3–8 минут. Используем для экспериментов, не для потока.

### Озвучка

- Основной вариант для русского: Yandex SpeechKit, оплата по российской карте, минута голоса стоит около рубля. Есть несколько естественных голосов.
- Альтернатива: ElevenLabs Starter за 5 долларов, лучше интонации, нужна иностранная карта.
- Локально бесплатно: Silero TTS, качество ниже, подходит для черновиков.
- Правило: у каждого канала свой голос. Площадки хуже относятся к одному голосу на десятке каналов.

### Сборка

- Python и FFmpeg. Скрипт берёт список кадров, аудио, сценарий и собирает видео 1080×1920, 30 кадров в секунду.
- Субтитры: Whisper локально выдаёт тайминги по словам, субтитры рисуются по 2–3 слова крупным шрифтом по центру.
- Музыка: фоновая из библиотеки с лицензией, громкость минус 18 дБ относительно голоса.
- Выход: файл MP4 и обложка PNG с первым кадром и заголовком.

### Проверка

Человек смотрит ролик один раз. Чек-лист:

- Первая секунда понятна без звука.
- Факты совпадают с карточкой товара.
- Призыв к действию есть.
- Нет чужих водяных знаков и логотипов.

Брак отправляется на пересборку с другим сценарием, не правится вручную.

### Публикация

- VK: метод загрузки клипов в API ВКонтакте через сообщество.
- YouTube: YouTube Data API, тип Shorts определяется форматом.
- Telegram: Bot API, пост с видео и партнёрской ссылкой в витрину.
- Max: ручная публикация до появления API, 2 минуты в день.
- TikTok: ручная публикация через приложение при наличии доступа, раз в день.
- Расписание: 1–2 ролика на канал в день в 12:00 и 19:00 по Москве. Планировщик cron на домашнем ПК или на VPS за 300 ₽ в месяц.

### Учёт

- Раз в сутки скрипт собирает просмотры из VK API и YouTube API, заказы выгружаются из кабинета Ozon вручную раз в неделю.
- Главная метрика: заказы на тысячу просмотров по каналу и по формату ролика.
- Еженедельно: 10 лучших роликов повторяются с новыми товарами, 10 худших форматов больше не делаются.

## 3. Что ставить на ПК

| Задача | Инструмент | Нагрузка на видеокарту |
|---|---|---|
| Картинки | ComfyUI, Flux Schnell GGUF или SDXL Lightning | 6–7 ГБ |
| Субтитры | Whisper, модель medium | 2–3 ГБ |
| Голос, запасной | Silero TTS | меньше 1 ГБ |
| Сборка | FFmpeg, Python | процессор |
| Видео, эксперименты | LTX-Video, Wan 2.1 1.3B | 7–8 ГБ, медленно |

Картинки и субтитры не запускать одновременно: 8 ГБ не хватит. Скрипт делает их последовательно.

## 4. Меры против санкций площадок

- Не больше 2 роликов в день на канал, не больше 6 каналов с одного IP.
- Разные голоса, шрифты и цвета субтитров на разных каналах.
- Аккаунты прогреваются 7 дней: просмотры, лайки, подписки на тематические каналы, и только потом первая публикация.
- Никаких покупных аккаунтов и накруток.
- Все ролики и сценарии хранятся локально. Потеря канала это потеря аудитории, но не контента.

## 5. Срок разработки

С опытом программирования с ИИ пайплайн версии 1 собирается за 10–15 часов, версия с автопубликацией и учётом за ещё 15–20 часов. Это недели 2–4 плана запуска.
